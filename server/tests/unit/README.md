# Unit Tests

This directory contains unit tests for the Office Queue server application.

## Running Tests

Install dependencies first:
```bash
npm install
```

Run all tests:
```bash
npm test
```

Run tests in watch mode (auto-rerun on file changes):
```bash
npm run test:watch
```

Run tests with coverage report:
```bash
npm run test:coverage
```

## Test Structure

- `ticketController.test.mjs` - Unit tests for the ticket controller
